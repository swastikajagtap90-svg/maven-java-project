# Maven Java Project

A simple Java application built and tested using Apache Maven.

## Technologies
- Java
- Apache Maven
- JUnit

## Build and Test
Run `mvn compile` to compile, `mvn test` to test, and `mvn package` to create the JAR file.

## Run the Application
`java -cp target/maven-java-project-1.0-SNAPSHOT.jar com.careertiq.app.App`

Expected output: `Hello World!`
